## Getting Started

### Local Development

```bash
npm install
npm run dev      # http://localhost:5173
```

### Docker

```bash
docker compose up dev --build    # Dev with hot reload
docker compose up prod --build   # Production (Nginx on :8080)
```

### Production Build

```bash
npm run build
npm run preview
```
